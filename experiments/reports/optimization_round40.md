# 优化记录 Round 40：cross-fitted 全局仿射校准

日期：2026-07-23

## 立项依据

组织方已明确允许“训练集或验证集拟合的固定全局校准”，并禁止使用测试集、
隐藏信息或排行榜反馈确定校准。当前 Round35 固定 70% base32 / 30% base48
集成已有完整五折 OOF 浮点预测缓存，因此可以不重训模型、不读取测试输入，严格
检验单一全局仿射变换能否修正稳定的输出强度偏差。

这与早期按测试 ROI 统计量缩放输出不同。本轮参数只来自官方训练集的 OOF
预测与标签，不使用 ROI 身份、DAPI 测试分布、排行榜分数或逐图规则；同一组
部署参数会自动应用于全部测试图像，因此可在复赛和决赛的新数据上按相同流程
重新拟合。

## 固定方法

底层预测固定为 Round35：

```text
p = 0.7 * Round31 base32 + 0.3 * Round34 continued-base48
```

校准只包含两个全局参数：

```text
p_cal = clip(a * p + b, 0, 255)
```

`a,b` 通过普通最小二乘解析求解，不搜索强度、正则、分段、gamma、ROI 参数或
融合权重。为避免把验证标签拟合回自身，对外层 fold `f`，只用其余四折的真正
OOF 预测和 target 拟合 `a,b`，再应用到 `f`。五折判定完成后，部署参数才用
全部 6296 张 OOF 训练图拟合一次。

实现以每折的像素充分统计量合并求解，不需要把四折像素复制到内存；校准发生
在 q95 JPEG 编码之前。评分严格使用组织方确认的逐图 RGB uint8 SSIM/PSNR
公式。本轮不计算 test-like 子集，以确保参数拟合和 gate 都不读取测试数据。

## 预注册 gate

相对未校准 Round35 baseline，必须同时满足：

1. 完整 OOF q95 官方分数至少提高 `+0.03`；
2. 完整 OOF float 官方分数严格为正增益；
3. 至少 4/5 folds 的 q95 官方分数为正；
4. 任一 ROI 的 q95 官方分数不得低于 `-0.10`；
5. 25 个 ROI 中负增益不得超过三个。

全部通过才允许用全 OOF 拟合的唯一 `a,b` 生成一次测试候选。任一失败即关闭
当前全局 affine，不追加 shrink strength、gamma、分位数映射、逐 ROI 校准或
排行榜探针。机器协议为
`configs/round40_cv5_global_affine_calibration.json`。

## 当前状态

实现与测试已完成。远端全量测试为 `207 passed, 63 subtests passed`；正式评估
复用了 Round37 缓存中的 6296 张 Round35 真 OOF 预测，用时 118.16 秒。

五个 cross-fit 校准器得到的斜率范围为 `1.00677-1.02889`，截距范围为
`0.48327-0.69216`；全部 OOF 拟合出的部署参数为：

```text
a = 1.0200918287
b = 0.5917317786
```

但这些参数不满足部署条件。完整 OOF 结果如下：

| 输出 | baseline | calibrated | delta |
|---|---:|---:|---:|
| float 官方分数 | 74.948362 | 74.549034 | -0.399328 |
| q95 官方分数 | 74.869164 | 74.191027 | -0.678137 |

q95 五折分别下降 `-0.722982`、`-0.799155`、`-0.850625`、
`-0.401243`、`-0.595209`，没有一个正增益 fold。25 个 ROI 中有 21 个下降，
最差 ROI 为 `ROI000`（`-1.492968`）。因此五项预注册 gate 全部失败。

OLS 的确把 float 全局 MSE 对应的 PSNR 从 `25.514353` 提高到
`25.543867`，但该目标与官方的逐图 PSNR 加 SSIM 聚合并不一致；强度放大尤其
损害了 SSIM，并且 q95 编码进一步扩大损失。这说明模型的剩余误差不是一个可由
统一亮度/对比度偏差解释的问题。

结论：关闭当前全局 affine 方向，不生成测试预测或提交包，也不追加 shrink、
gamma、分位数映射、逐 ROI 校准或排行榜探针。完整机器结果见
`reports/round40_cv5_global_affine_calibration_oof.json`。
