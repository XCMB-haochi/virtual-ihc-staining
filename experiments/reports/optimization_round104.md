# 优化记录 Round 104：输出编码与活动度诊断

## 目的

Round103 关闭了无新机制的监督续训。本轮不训练模型，先检查两个可能影响后续
决策的因素：提交图像编码是否造成明显额外损失，以及当前模型误差是否集中在
可由训练标签定义的高活动度图像。

## 输出编码审计

使用现有 Round37 五折、无泄漏 OOF 缓存的固定 `0.7*base32 + 0.3*base48`
浮点预测，覆盖 6296 张图；每种编码都先取同一 `uint8` 四舍五入值，再解码后
按官方逐图 SSIM/PSNR 计算。完整结果如下：

| 编码 | 官方分 |
| --- | ---: |
| JPEG q75 | 74.641140 |
| JPEG q90 | 74.831514 |
| JPEG q95 | 74.869164 |
| JPEG q98 | 74.872305 |
| JPEG q100 | 74.853404 |
| PNG 无损 | 74.889786 |

PNG 相对 q95 仅提高 `+0.020622`，q98 仅提高 `+0.003140`。因此编码可以作为
一次固定格式确认，但不是当前榜单差距的主要来源；不做逐图编码选择或 JPEG
量化表搜索。抽样和完整报告分别为 `reports/round104_encoding_sample.json`
和 `reports/round104_encoding_full.json`。

## 活动度与误差

对每张训练目标定义固定活动度：`std + 平均相邻像素差 + 0.25*前景比例 +
0.25*p95`。在同一 OOF 缓存上，目标活动度与基线 MSE 的 Pearson 相关为
`0.5856`。按目标活动度四分位，基线 MSE 从低组 `86.95` 增至高组 `354.32`。
这一相关性只用于说明训练集中的困难样本结构，不把测试输入统计量带入任何
训练配方、路由或校准。

一个固定 Ridge 交叉拟合的逐图均值/对比度校正抽样（500 张）把 q95 从
`75.0365` 降至 `73.47/73.89`；目标均值 oracle 也因 SSIM 损失而下降，只有
同时知道目标均值和标准差的 oracle 才显示出不可部署的上限。因此关闭公开
DAPI 特征的逐图强度校正，不扩展该诊断。

## 决策

活动度是可解释的困难样本信号。下一轮 Round105
只测试一个训练期机制：在每个 stage 后 25% epoch 中，用训练集 CD68 目标活动度
最高四分位替换固定 30% 的采样位置；其余样本和所有验证/测试流程不变。该
sampler 不读取测试标签、测试统计或排行榜反馈，候选先做 fold0/fold2 OOF gate。
