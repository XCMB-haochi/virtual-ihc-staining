# 优化记录 Round 106：跨 ROI DAPI 近邻检索诊断

## 目的与边界

Round105 的目标活动度重采样失败，说明困难样本不能靠简单改变采样分布解决。
本轮转向一个完全不同、无需 GPU 的诊断：如果训练 ROI 中存在形态相似的 DAPI
patch，直接检索其 CD68 target 可能提供与卷积模型不同的先验。该方法只使用
训练集 OOF 缓存；每个外层 fold 的检索库来自另外四个 fold，严格不含该 fold
的 target。

## 固定方法

- DAPI 特征：原始和按自身均值/标准差标准化的 `16x16` 平均池化图，加七个
  强度/梯度摘要；
- 检索：标准化特征上的欧氏距离，固定 `k=4`，四个邻居 target 做像素平均；
- 对照：Round37 OOF cache 的固定 `0.7*base32 + 0.3*base48` 预测，统一应用
  已验证的 `[0,-1]` 输出偏移；
- 候选：检索 target 与该对照固定 `90%/10%` 融合，同样应用 JPEG q95 和
  官方逐图 SSIM/PSNR；
- 评估：五折 cross-fit、6296 张图、25 个 ROI；不读取测试图像或测试标签。

## 预注册判定

固定 blend 只有在 q95 至少提高 `+0.02`、float 为正、至少 4/5 folds 和 15/25
ROI 为正且最差 ROI 不低于 `-0.08` 时，才值得把同一检索器移植到当前 UNeXt2
OOF cache。否则关闭检索路线，不搜索邻居数、融合权重、特征距离或测试时路由。

## 完成审计与结果

远端 Screen 已结束，OOF 报告覆盖五折、6296 张图和全部 25 个 ROI，退出过程
无错误。每个 holdout fold 的检索库均由另外四折组成，最近邻距离均值约
`22.47--23.09`，没有出现近重复匹配。

| candidate | 官方 q95 分 |
| --- | ---: |
| 固定神经网络基线（已移位） | 74.986058 |
| k=4 近邻 CD68 target | 47.247373 |
| 基线 90% + 近邻 10% | 72.217157 |

固定融合相对基线下降 `-2.768900`；五个 fold 全部下降，最近邻单独输出也在
每个 fold 失败。OOF 报告 SHA-256 为
`96409d9953f393ca791e83c1c66e0f3d7f17f28594fc25e51c46c9e84ebd88b0`。

## 决策

关闭跨 ROI DAPI 近邻检索及其简单固定融合，不搜索邻居数、特征距离、检索
置信度或逐图路由。训练集中的困难图像不是可通过形态复制解决的误差；后续应
继续寻找能学习 DAPI-to-CD68 条件映射的独立表示或训练目标。
