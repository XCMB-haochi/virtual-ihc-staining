## 计算规则

令 `w` 为 seed2027 权重。对每个 ROI，服务器端点分数为 `S0`（`w=0`）与 `S1`（`w=1`）：

```text
delta0 = S0 - B_raw
delta1 = S1 - B_raw
x = 2*w - 1
q(x) = a*x^2 + b*x
a = (delta0 + delta1) / 2
b = (delta1 - delta0) / 2
```

若 `H=delta0+delta1<0`，凹曲线顶点为：

```text
w_star = 0.5 + (delta0-delta1)/(4*H)
gain_star = -(delta1-delta0)^2/(8*H)
```

每个 ROI 比较 `w=0`、`0.5`、`1` 和合法凹顶点，取预测贡献最大的候选。只有同时满足以下条件才生成中间权重：

- `H < -0.001`；
- `w_star` 位于 `[0,1]`；
- 顶点相对三个实测点的额外预测收益至少 `0.005`，优先使用 `0.01` 门槛。

否则只选择实测端点或 50/50。四位总分下，单个 `delta` 最坏舍入误差约 `0.0001`，五 ROI 端点组合的纯舍入误差最坏约 `0.00045`。
