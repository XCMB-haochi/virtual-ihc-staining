# DAPI 虚拟免疫染色

基于 ConvNeXt V2、域内 FCMAE 预训练和标记条件学习的虚拟染色项目。仓库包含最终半决赛方法，以及初赛、复赛和半决赛的实验过程。

赛题：[2026 AIC · 基于虚拟染色的免疫组化图像生成](https://www.aicomp.cn/tracks/tracks-1/3759.html) · [赛题说明与规则（PDF存档）](docs/规则/赛题说明与规则.pdf)。

团队：通信速通生物。

## 最终方法

一个共享模型接收单张 DAPI 和目标 marker 编号，生成同尺寸的目标染色图像。四级编码特征通过 marker FiLM 调制，解码器采用跳跃连接和 PixelShuffle。

训练流程包括 800 轮域内预训练、五个 ROI 留出教师、逐图教师目标生成，以及 14 + 12 轮全量学生训练。学生第二阶段结合真实标签、教师目标和几何一致性损失。

| 数据集 | Marker | 半决赛平台分数 | 权重 |
|---|---|---:|---:|
| Colon | CD68 | 73.1963 | 10% |
| Liver | CD45RO | 78.7011 | 20% |
| Stomach | CD68 | 72.8684 | 70% |
| 加权结果 | | **74.0677** | |

复赛最终成绩为 79.1052，排名全国第一；半决赛最终成绩为 74.0677，排名全国第六。

半决赛按单张完整 DAPI、共享模型与单一 checkpoint、单目标输出进行评价，采用单次前向推理。复赛方案中的上下文输入和 TTA 在这一阶段调整为标记条件共享网络及训练几何一致性约束。阶段要求见[半决赛注意事项](docs/规则/半决赛注意事项.pdf)，各轮方法与结果见实验档案。
